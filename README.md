# حلیم تبریز

طرح اولیه لندینگ فارسی و راست‌به‌چپ، با الهام از ساختار سایت https://www.esfahanrestaurant.com/ و هویت بصری ارائه‌شده توسط کاربر.

## پالت

- قرمز ایرانی: `#892320`
- سبز: `#2F5D50`
- طلایی زعفرانی: `#D1AC3F`
- کرم: `#F2E6D8`

لوگو عیناً از فایل کاربر کپی شده است. عکس غذا نمایشی و تولیدشده است. متن معرفی و اقلام منو پیشنهادی‌اند و پیش از استفاده عمومی باید با اطلاعات واقعی جایگزین شوند. اطلاعات تماس، قیمت، سابقه تأسیس یا ادعای مشتریان ساخته نشده است.

## ویرایش

- `dist/index.html`: متن و ساختار صفحه
- `dist/style.css`: رنگ‌ها و ظاهر واکنش‌گرا
- `dist/app.js`: منوی دسته‌بندی و ناوبری موبایل
- `dist/hero-effects.js`: بخار و ریزش و تجمع دارچین در Hero؛ تنظیم‌ها در `CONFIG` ابتدای فایل.
- `dist/assets/hero-bowl-cutout.png`: نسخهٔ شفاف کاسهٔ ارسالی؛ زمینهٔ شطرنجی با ابزار داخلی ImageGen حذف شده است. تصویر در طول انیمیشن کاملاً ثابت است.
- `dist/assets/hero.png`: تصویر نمونه؛ برای تعویض، تصویر واقعی را با همین نام جایگزین کنید.
- `dist/assets/logo.png`: لوگوی ارائه‌شده

سایت استاتیک است و ثبت سفارش یا رزرو آنلاین ندارد.

## تنظیم افکت Hero

- `CONFIG.emitter.x/y`: نقطهٔ برخورد دارچین، به نسبت عرض و ارتفاع تصویر کامل از گوشهٔ بالا سمت چپ؛ `spread` پهنای ریزش است.
- `CONFIG.steamSources`: نقاط شروع بخار با همان دستگاه مختصات.
- `CONFIG.cinnamon.speed`: سرعت سقوط؛ `particlesPerSecond` نرخ تولید؛ `maxParticles` سقف تعداد زنده؛ `size` اندازهٔ ذرات.
- `CONFIG.deposit.width/height`: شعاع محل تجمع روی فضای خالی بین پیاز و پسته؛ `grains` تعداد دانه‌های بافت ثابت.
- `CONFIG.duration`: طول چرخه، ۵٫۸ ثانیه. در حالت کاهش حرکت افکت‌ها خاموش می‌شوند؛ خارج از دید و هنگام پنهان‌بودن صفحه توقف دارند.
- تصویر فقط با CSS واکنش‌گرا اندازه می‌گیرد؛ هیچ انیمیشن، transform یا transition روی تصویر یا کاسه وجود ندارد.

پالت از PDF کاربر: قرمز `#892320`، سبز `#2F5D50`، کرم `#F2E6D8` و طلایی `#D1AC3F`. زمینهٔ Hero کرم است و متن و دکمه از قرمز و سبز استفاده می‌کنند. سایر بخش‌ها حفظ شده‌اند.

دستور ویرایش تصویر با ابزار داخلی ImageGen: فقط پس‌زمینهٔ شطرنجی را با شفافیت واقعی جایگزین کن؛ فرم، قاب، زاویه، جنس کاسه و جزئیات حلیم، پیاز و پسته را حفظ کن و هیچ بخار، دارچین یا شیء تازه‌ای اضافه نکن. خروجی استخراج‌شدهٔ تولیدی است و حفظ پیکسل‌به‌پیکسل جزئیات تضمین نمی‌شود؛ PNG شفاف اصلی کاربر می‌تواند با همین ابعاد و قاب جایگزین شود.
