# حلیم تبریز

سایت استاتیک فارسی با پس‌زمینهٔ Hero به رنگ #892320.
مدل ارسالی کاربر در assets/halim-bowl.glb با نمایشگر محلی model-viewer 4.0.0 نمایش داده می‌شود.
دوربین ۵۲ درجه از محور قائم فاصله دارد؛ نمای داخل و بدنه هم‌زمان دیده می‌شود.
چرخش افقی کامل هر ۲۰ ثانیه انجام می‌شود و با کاهش حرکت یا پنهان شدن صفحه متوقف می‌شود.
تمام ویدیوها از خروجی سایت حذف شده‌اند. متن‌ها و منو واکنش‌گرا هستند.

ویرایش: dist/index.html، dist/style.css، dist/hero-effects.js و dist/app.js.
